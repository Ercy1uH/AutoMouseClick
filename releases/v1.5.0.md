# MouseClik 1.5.0

## 新增与改进

- 新增循环块：对一组点击与等待步骤设置重复次数，显示当前循环和整体执行进度。
- 支持在循环内添加、调整步骤；循环坐标与主序列坐标使用不同深浅颜色，支持拖动定位、撤销和折叠后继续插入。
- 配置名称支持内联编辑、确认和取消；增加空名称检查并改善长名称显示。
- 悬浮条增加配置信息，调整布局和窗口尺寸，改善长标题、运行详情和不同缩放下的控件显示。
- 配置格式升级到 v5，为步骤保存稳定 ID；旧版本配置迁移时保留原文件备份。

## 修复与工程整理

- 加强点击前的目标窗口检查，修复 PowerShell 编码对右键、中键与双击识别的影响。
- 完善配置写盘、重启恢复、服务身份验证、测试进程清理及构建产物校验。
- 测试按 `ui/`、`e2e/`、`desktop/`、`manual/` 分类；更新说明与构建记录集中到 `releases/`。
- 更新 README 的下载、使用、测试和构建说明。
- 移除在线字体请求，使用系统字体回退，避免网络字体影响界面加载。

## 下载

- `MouseClik-1.5.0-portable.exe`：Windows 10/11 x64 便携版，无需安装 Node.js。
- `MouseClik-1.5.0-portable.exe.sha256`：对应可执行文件的 SHA-256 校验值。

## 已知限制

- 不支持嵌套循环，空循环不能启动。
- 配置升级前建议备份现有配置；旧版程序不能直接读取 v5 配置。
- 自动化界面缩放检查不等于真实窗口的 DPI 点击验证；实际外部窗口在不同权限和系统缩放下仍需检查点击位置。
